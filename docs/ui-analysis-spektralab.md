# SpektraLab 界面组成分析

> 目的：搞清楚 SpektraLab 的界面为什么看起来"专业"，哪些结构可以搬到 SpektraRoll，
> 哪些是静态照片专用、不该照抄。
>
> 分析对象：`JamesQiu2005/SpektraLab`，GPL-3.0，commit `3915092`，应用版本 1.3.4。
> 这份分析基于公开仓库里的 `windows_UI/qml`、`screenshots/`、`ARCHITECTURE.md`、
> `windows_UI/DESIGN_ALIGNMENT.md`，**没有反编译二进制**。
>
> 结论先行：它好看不是因为某一个控件，而是因为四件事同时成立——
> ① 三栏 + 顶栏 + 底栏的固定骨架；② 一套克制的灰/琥珀色令牌；
> ③ 所有参数都长成同一种"标签 + 数值 + 细滑块"；④ 画布永远占据最大面积。
> SpektraRoll 的 v2 界面就是按这四点重排的。

## 1. 窗口骨架

SpektraLab 的 macOS 原版（`screenshots/Screenshot_English.png`，2560×1440）：

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ 顶栏 38px：导入 · 导出 · 裁切 · 撤销/重做 │ Process | Original │ 100% 适合 100% │
├───────────────┬──────────────────────────────────────────────┬───────────────┤
│ 左栏 246px    │ 画布（ground #5f5f5f）                        │ 右栏 288px    │
│               │                                              │               │
│ Film and Print│         照片以"适合窗口"居中，四周留 18px      │ Parameters    │
│               │         右上角：FULL 徽章 + 直方图             │ Pre-Dev       │
│ ▾ 导航图      │                                              │ Post-Dev      │
│   缩略图 132px│                                              │               │
│ ▾ 胶片        │                                              │ ▾ 宽容度      │
│   正片/负片   │                                              │   曲线 + 统计 │
│ ▾ 相纸        │                                              │ ▾ 输入/相机   │
│   174px 列表  │                                              │   曝光/色温…  │
│ ▾ 裁切        │                                              │ ▾ 胶片画幅    │
│ ▾ 放大机      │                                              │   颗粒/光晕…  │
│               ├──────────────────────────────────────────────┤               │
│               │ 画布状态条 28px：尺寸 · 色彩空间 · 状态        │               │
│               ├──────────────────────────────────────────────┤               │
│               │ 照片条 160px：132px 缩略图 + 勾选 + 左右箭头  │               │
└───────────────┴──────────────────────────────────────────────┴───────────────┘
```

Qt Windows 版（`windows_UI/qml/Main.qml`）把同一套骨架压成三栏：

- `ApplicationWindow`：1540×980，最小 1100×740，`font.family: "Segoe UI"`，`pixelSize: 12`
- 左栏 `Layout.preferredWidth: Theme.leftWidth`（246）
- 中间 `Layout.fillWidth`（ground）
- 右栏 `Theme.rightWidth`（288）
- 顶栏 `Theme.topHeight`（38）
- 底栏 `Theme.stripHeight`（160）
- 栏与栏之间 `spacing: 1`，分隔线就是 1px 的 ground 透出来

**关键比例**：左右两栏加起来不到窗口的 40%，画布始终是主角；顶栏/底栏都很矮，
只有 38/160px，不会挤压画布。

## 2. 设计令牌（Theme.qml）

这些值直接来自 `windows_UI/qml/Theme.qml`，是 SpektraLab 观感的核心：

| 令牌 | 值 | 用途 |
|---|---|---|
| `ground` | `#5f5f5f` | 画布四周的中灰底；与深色栏形成"照片放在灯箱上"的层次 |
| `card` | `#2d2d2c` | 顶栏、左右栏、底栏 |
| `well` | `#484846` | 输入框、按钮的底 |
| `wellDark` | `#1e1e1c` | 缩略图底、日志、进度条槽 |
| `text` | `#faf8f4` | 主文字（偏暖的白，不是纯白） |
| `muted` | `#b7b6b3` | 次要文字、数值、状态 |
| `accent` | `#e1a95f` | 琥珀色：选中、主按钮、滑块已走部分、勾选 |
| `line` | `#858582` | 分隔线（0.55 透明度使用） |
| `selection` | `#f1f0eb` | 列表选中行底色（原版胶片列表是白底黑字） |
| `selectionText` | `#252523` | 选中行文字 |

字号层级同样克制：

- 应用/栏标题：**14px bold**
- Section 标题：**13px bold**
- 参数标签/正文：**11px**
- 数值、说明、状态：**10px**
- 徽章：**9px + 字距 1px**

圆角只有 2–4px；没有阴影、没有渐变、没有大色块。专业感来自"少而一致"。

## 3. 组件清单

### 3.1 顶栏

- 左侧动作：导入、导出、裁切、撤销、重做（`ActionButton`，27px 高）
- 中间：`Process | Original` 分段控件（原版 SwiftUI），Windows 版暂未接
- 右侧：缩放百分比、`适合` / `100%` 两个按钮
- 全部是同一尺寸的扁平按钮；主操作只用琥珀描边，不填充

### 3.2 左栏（材料选择）

- 栏标题 `胶片与相纸`，14px bold，固定 38–42px 高
- `Section`：1px 分隔线（55% 不透明）→ 13px bold 标题 → 10px 间距 → 14px 左右内边距
- **导航图**：132px 高的暗底缩略图 + 适合按钮 + 缩放百分比
- **胶片**：按 Positive / Negative / B&W 分组，行高 27px；选中行是浅色底 + 深色字
- **相纸**：174px 高的滚动列表；反转片时整组变灰并显示"反转片直接扫描，不使用相纸"
- **裁切 / 放大机**：比例下拉、旋转/翻转、拉直滑块、相纸亮度、黄/洋红滤镜

材料是"列表 + 选中"，不是下拉框——因为用户要反复比较不同胶片。

### 3.3 画布（中间）

- 背景 `ground`，照片四周留 18px
- 右上角 `FULL` 徽章：9px、字距 1px、深色半透明底
- 右上角直方图叠加（macOS 原版），与参数栏的宽容度图呼应
- 空白状态：应用名 32px、说明 13px、提示 11px，居中
- 画布下方 28px 状态条：`5504 × 8256 · SDR sRGB / 8 位预览 · 更新预览中…`
- 拖放区域覆盖整个画布，支持一次多张

### 3.4 右栏（参数）

- 顶部三个 tab：`Parameters | Pre-Dev | Post-Dev`（原版）；Windows 版是单栏滚动
- 每个 Section 里是统一的行：
  - 标签（11px）在左，数值（10px，muted）在右
  - 下面一条 24px 高的细滑块
  - 开关型效果：复选框 + 强度滑块（`Effect` 组件）
- 典型分区：输入/相机、胶片画幅与效果、RAW 解码、照片信息、状态
- 说明文字（Note）10px、muted，解释"这个参数为什么存在"，不是装饰

### 3.5 底栏（照片条）

- 160px 高；顶部 1px 分隔线
- 左：`N 张照片 · 已选 M`
- 右：全选、清除选择、同步设置
- 缩略图 132px 宽，当前照片 2px 琥珀描边；右上角勾选框
- 缩略图显示**裁切后的画面**，与画布一致（原版有专门的 SurfaceAgreement 测试）

### 3.6 通用控件

- `ActionButton`：padding 9、字号 12、圆角 3；hover `#585752`、pressed `#686762`；
  `accented` 时底色 `#645039` + 1px `accent` 描边
- `Section`：分隔线用 `Theme.line` 55% 透明，标题 13px bold
- 滑块：轨道 2px，已走部分 accent，手柄 10px 白色
- 数值：永远右对齐、等宽感（10px），拖动时实时更新
- 列表行：27px，选中是"浅底深字"，不是蓝色系统高亮
- 滚动条：细、无箭头、深色

## 4. 交互与状态规则

这些规则比样式更值得学：

1. **改参数自动出预览**：180ms 静默期合并连续拖动；不是每改一次点一次"应用"。
2. **适合 / 100%**：`Ctrl+0` / `Ctrl+1`，双击画布也能切换；100% 是物理像素 1:1。
3. **原片对比**：顶栏 `Original` / 分屏；不改变编辑状态。
4. **每张照片独立设置**：切换照片恢复各自的胶片、相纸、效果、裁切；未完成的参数也保留。
5. **批量导出串行**：冻结来源、设置、裁切和选择集合；取消只在完整文件之间生效；
   已存在的目标文件默认保留，不覆盖。
6. **设置自动保存**：应用本地数据目录，重新打开同一路径恢复；源文件目录只写导出。
7. **失败可见**：渲染失败保留上一帧，状态区给出原因和"重试"。
8. **撤销/重做**：每张照片 64 步；一次滑块拖动合并成一步。
9. **键盘优先**：`Ctrl+O/E/0/1/Z/Shift+Z`，`Enter/Esc` 确认/取消裁切。
10. **禁用而不是隐藏**：不适用的控件变灰并给 Note 解释（例如反转片时的相纸）。

## 5. 映射到 SpektraRoll（视频，不是照片）

| SpektraLab | SpektraRoll v2 | 说明 |
|---|---|---|
| 三栏 + 顶栏 + 底栏 | 三栏 + 42px 顶栏 | 画布居中，左材料、右参数 |
| 左栏：胶片/相纸列表 | 左栏：素材 / 胶片与相纸（LUT）/ 输出 | 我们只有一对 profile，用 LUT 文件 + 烘焙代替长列表 |
| 右栏：Parameters 多 tab | 右栏：参数 / 队列 / 日志 | 曝光、扫描、反差、质感放参数；队列和日志各占一个 tab |
| 底栏：照片条 | 画布下：元数据条 + 时间线 + 状态条 | 视频没有"多张照片"，但有时间线和队列 |
| 画布 18px 留白 + ground | 同样 18px + `#5f5f5f` | 直接采用 |
| Process / Original | 工具栏"按住看原片" | 按住显示解码原片，松开回成片 |
| 适合 / 100% | 暂只有适合窗口（FIT 徽章） | 缩放/平移是下一步 |
| 直方图叠加 | 暂未做 | 需要从预览 QImage 统计，下一步 |
| 照片条勾选/批量 | 渲染队列：多任务、进度、ETA、持久化 | 视频的"批量"是队列而不是照片选择 |
| 自动保存每张照片 | 队列持久化 + 界面参数 QSettings | 已有 |
| RAW 解码、裁切、画幅、放大机 | 不适用 | 视频走 Apple Log / ffmpeg，不引入 RAW 概念 |

## 6. 本次在 SpektraRoll 落地的部分

已经在 `src/ui-qt/main.cpp` 实现：

- 全局 QSS + QPalette：`ground/card/well/text/muted/accent/line` 令牌、Segoe UI 9pt、
  2–3px 圆角、细滑块、琥珀主按钮
- 42px 顶栏：标题、预览/看原片/渲染/入队/取消/输出文件夹、文件名、FIT 徽章
- 左栏：`胶片与印相` + 可折叠 Section（素材 / 胶片与相纸 / 输出）
- 中间：`#5f5f5f` 画布 + 18px 留白、元数据条、时间线、状态条（进度条）
- 右栏：`参数 / 队列 / 日志` 三个 tab；参数用统一的 `SliderRow`
  （标签 + 数值 + 细滑块）和可折叠 Section
- 队列与日志从底栏移入右栏，画布不再被表单挤压

对应截图：`docs/ui-preview.png`、`docs/ui-queue.png`。

## 7. 还没抄的（按价值排序）

1. **直方图叠加**：从当前预览 QImage 算 256 桶，画在画布右上角；成本低、专业感强。
2. **适合 / 100% 缩放 + 拖拽平移**：需要把 PreviewView 改成可缩放视图。
3. **画布下方状态条显示"渲染中/复用"**：已有文字，可加颜色状态点。
4. **胶片/相纸长列表 + 预设**：需要更多 profile，属于内容侧。
5. **裁切/画幅**：视频版可以后置裁切，但不是当前优先级。
6. **照片条式队列缩略图**：用队列任务的输出首帧做缩略图，成本较高。
