# macOS UI 设计规格（D073 · v1）

> 产品负责人 2026-11-05 的设计输入。实现以本文件 + `design/tokens.json` + `data/ui-schema.json` 为准。
> 参考 SpektraLab 的**三栏工作流**，但不复制其源码、图标、截图或任何资产。

## 1. 整体

- 深色/近黑品牌界面；**白色药丸按钮 + 黑色文字**。
- 字体：**思源黑体（Source Han Sans SC）**；标题加粗。没有安装时回退 Noto Sans SC → PingFang SC → 系统。
- 平台自适应：macOS 使用原生窗口、菜单、文件选择器；视觉 token 与 Windows 版保持一致。
- 窗口最小 1280×800，默认 1440×900。

```
┌──────────────┬──────────────────────────────────────┬──────────────────────┐
│ 底片         │              播放区域                │ INFO FILM PRINT      │
│ (220 pt)     │              (flex)                  │ ADVANCED OUTPUT      │
│              │                                      │ (380 pt)             │
│ 缩略图 1     │   ┌──────────────────────────────┐   │                      │
│ 缩略图 2     │   │                              │   │  当前 tab 内容       │
│ 缩略图 3     │   │        视频 / 胶片预览        │   │                      │
│              │   └──────────────────────────────┘   │                      │
│ + 导入       │   ▶ 00:12 / 00:30   [胶片效果]       │                      │
└──────────────┴──────────────────────────────────────┴──────────────────────┘
```

## 2. 左侧：底片

- 标题 **底片**（加粗，14pt），右侧显示素材数量。
- 单列缩略图；卡片 16:9，高约 96pt；显示文件名、分辨率、时长/帧率。
- **双击空白区域**：打开 `NSOpenPanel`，可同时选择视频文件或项目目录。
  - 选目录：递归扫描 `mov / mp4 / mxf / r3d`（v1 只播放前三种；R3D 显示“仅 Windows”）。
  - 选文件：直接导入。
- **双击缩略图**：载入中间播放区域。
- 单击缩略图：只选中，不载入。
- 右键：在播放器中打开 / 从底片移除。
- 导入时弹出 **输入选择** 面板：
  - 下拉 1：`画面类型` / `色彩管理（OCIO）`。
  - 若选画面类型：下拉 2 列出 10 种（sRGB、Apple Log、S-Log3、S-Gamut3、C-Log3、V-Log、LogC3、LogC4、BMD Film Gen5、DaVinci Intermediate）。
  - 若选 OCIO：下拉 2 列出 `ocio-info --json` 的空间；默认 `S-Log3 S-Gamut3.Cine`。
  - **不要求用户指定配置文件**；后台自动使用 `data/ocio/studio-config-v3.0.0_aces-v2.0_ocio-v2.4.ocio`。
  - 多选/目录导入时，选择“应用到全部”。
- 素材选择持久化到 `~/Library/Application Support/SpektraRoll/library.json`。

## 3. 中间：播放区域

- 黑色画布，视频按比例居中；无系统播放控件。
- **空格**：播放 / 暂停；再次空格暂停。
- 底部浮层：播放/暂停、当前时间/总时长、`胶片效果` 开关、状态提示。
- `胶片效果` 关闭时播放原片；开启且暂停时，用 CLI 渲染当前帧的胶片效果并显示。
- 渲染中显示进度条和“取消”。
- 没有素材时显示空状态：“从左侧双击导入素材”。

## 4. 右侧：检查器

顶部 5 个 tab：**INFO / FILM / PRINT / ADVANCED / OUTPUT**。选中项白色下划线；未选中灰色。

### INFO
- 文件名、路径、分辨率、帧率、时长、总帧数、codec、色彩标签、timecode。
- 引擎状态：CLI 版本、OCIO 版本、GPU 后端、RED 可用性。
- `色彩管理` 当前选择（画面类型或 OCIO 空间）。

### FILM
- **画幅**：35mm / Super 35 / 16mm / Super 16 / 65mm / IMAX（映射 `--frame-width-mm`）。
- **胶片**，按分类：
  - 彩色负片（still negative）
  - 电影负片（Vision3 / Verita）
  - 反转片（Ektachrome / Velvia / Provia / Kodachrome）
  - 每项显示名称 + 参考光/类型徽标；选中白色边框。
- **质感**（在胶片下方）：
  - 颗粒 `--grain` + 稳定度 `--grain-rate`
  - 光晕 `--halation`
  - **防光晕层**：v1 是 UI 级开关（开启时光晕按 0.6 倍计算）；同时显示 profile 的 `antihalation` 值。等引擎有独立参数后改为真实参数。
  - 耀光 `--glare`
  - 扩散 `--diffusion`
- 选反转片时：自动切 `scan=slide`、禁用相纸、反差默认 1.0。
- 选负片时：自动选 `targetPrint`，反差默认 1.15。

### PRINT
- **第二层**，按分类：
  - 相纸（6 种）
  - 电影印片（2383 / 2393）
- **扫描方式**：扫描负片 / 扫描印片 / 扫描反转片（直扫）。
- 反差 `--contrast`（18% 中灰支点）。
- OkLCh 色域压缩 `--gamut oklch|off`。
- 反转片时相纸区域禁用并显示说明。

### ADVANCED
- 曝光 `--exposure`
- DIR 耦合剂 `--couplers on|off`
- 引擎：LUT / 光谱 CPU / 光谱 GPU
- GPU 质感：自动 / CPU / GPU
- LUT 插值：四面体 / 三线性
- 强度 `--strength`
- OCIO 状态（只读；配置自动选择）
- 线程 `--threads`（0 = 自动）

### OUTPUT
- 编码：H.264 / HEVC / ProRes 422 HQ
- 传输：SDR / HDR PQ / HDR HLG
- 质量：CRF / preset（ProRes 时隐藏）
- 输出目录（选择按钮）+ 文件名
- **渲染** 白色药丸按钮；渲染中显示进度、耗时、取消
- 日志：最近 200 行；`{` 开头的 JSON 行进进度，其余进日志

## 5. 组件规则

- 主按钮：白色胶囊、黑字、高 32、左右 16、13pt semibold。
- 次按钮：深色胶囊、白字、1px 边框。
- Tab：高 40、选中白字 + 2px 白线、未选中灰字。
- 缩略图：8pt 圆角、选中 2px 白边、未选中 1px `#242428`。
- 面板：`#0F0F11`、1px `#242428`、8pt 圆角。
- 滑块：细轨、白色拇指；数值右对齐。
- 分隔线：`#242428`，1px。
- 不使用 macOS 默认蓝色 accent；选中态用白色。

## 6. 参数映射

所有参数以 `data/ui-schema.json` 为准。UI 只负责：

1. 生成 CLI argv；
2. 把 `catalog --json` 的片库分组显示；
3. 把 `ocio-info --json` 的空间填进下拉；
4. 把 `--progress json` 的事件映射到进度条；
5. 错误文本原样进日志，状态栏给中文摘要。

## 7. v1 范围

**做：** 导入/缩略图、播放/暂停、胶片效果单帧预览、片库、画幅、质感、印片/扫描、曝光/反差/耦合剂/色域、LUT/光谱引擎、渲染、进度、取消、设置持久化、中英文案（先中文）。

**不做：** 时间线拖动/逐帧预览、R3D 播放、裁切、印片机 Y/M/预闪、扫描仪 unsharp、空间物理模型、Mac App Store、自动更新。

## 8. 验收

1. 双击 `SpektraRoll.app` 能启动，无终端。
2. 双击左侧空白 → 选 `C0113.MP4` → 输入选择面板 → 缩略图出现。
3. 双击缩略图 → 中间播放；空格播放/暂停。
4. 右侧 FILM 选 Portra 400 / Vision3 500T，PRINT 自动切换。
5. `胶片效果` 开启并暂停 → 当前帧显示胶片效果。
6. OUTPUT 选 ProRes → 渲染 2 秒 → 输出文件可播放，音频/timecode 保留。
7. 退出重启 → 素材库和参数恢复。
